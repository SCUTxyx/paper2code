# Embodied-paper applicability precheck (具身论文适用性预检)

本文件细化 SKILL.md §S2 的适用性预检，专用于具身智能（机器人操作/移动/VLA/策略学习/
模型型控制/仿真基准）论文。原则不变：**验证数学，不跑训练**；具身场景下还加一条——
**快速、有据地回答"这篇论文能否复现、能复现到哪一层"**，替用户省掉一周后才发现
"跑不了"的成本。

## 1. 概念对齐（必须写进报告开头）

社区语境的"复现具身论文"通常指"跑通官方代码 + 真机 demo"，需要真机、权重、数据集。
本 skill 的复现定义是**数学核验证**。两者不同，REPORT 必须先声明，避免预期错位。

## 2. 预检决策树（S2 阶段执行，逐问落档）

- **Q1 论文里是否存在"给定输入 → 解析输出"的数学件？**（一个公式/算法框即可）
  - 没有（纯系统/纯实验报告）→ 判定 ❌，产出 1 页 WHY-NOT 报告
    （列出缺什么：权重/真机/数据/训练时长）——这个否定性产出本身有价值。
  - 有 → 进 Q2。
- **Q2 数学件属于下面哪一类？**（决定测试类型，见 §3）
  - A 生成式动作头；B 时序聚合/动作分块；C 模型型控制；D 几何与运动学；
    E 估计与滤波（EKF/SLAM、已有 Kalman 考卷背书）→ 进入正常六阶段。
- **Q3 有没有必须依赖真机/训练权重/大规模数据的声称？**（成功率、泛化、sim2real）
  - 有 → 逐条列入 GAP_LIST，并在 FEASIBILITY 里降档。
- **Q4 学习到的模块（视觉编码器、策略网络权重）是否是数学件的依赖？**
  - 是 → 用合成输入替代（数学件对合成输入的性质照样可验证），并在 REPORT 声明。

## 3. 五类可测数学件 → 测试类型映射

| 类 | 典型例子（已核实原文） | 测试类型 |
|---|---|---|
| A 生成式动作头 | Diffusion Policy 的 DDPM 头（训练 MSE + DDIM 推理）；flow matching 的向量场 ODE；ACT 的 CVAE | 闭式边缘恒等式、确定性采样链、损失梯度 |
| B 时序聚合/动作分块 | ACT temporal ensembling：`w_i = exp(−m·i)`（i 为预测年龄），`a_t = Σ w_i A_t[i] / Σ w_i`（ACT §IV-A 原文，已核实）；Diffusion Policy 的 receding-horizon 承诺执行（T_p=16, T_a=8） | 权重归一化、年龄单调性、窗口性质、缝合语义 |
| C 模型型控制 | iLQR/DDP（动力学线性化、Bellman backward）、CBF 前向不变性、MPC 的递推 | 线性化 vs 有限差分、代价单调下降、不变集、KKT/平稳条件 |
| D 几何与运动学 | FK/IK、SE(3) 群运算、手眼标定 | 群封闭性/结合律、正逆解一致性 |
| E 估计与滤波 | EKF-SLAM、粒子滤波 | 与批量闭式解对拍（Kalman 考卷已背书） |

## 4. 三档可行性判定（写进 METHOD_CARD 头部 FEASIBILITY 区块）

- **✅ REPRODUCIBLE-MATH**：数学核可在此环境完整验证（如 iLQR on pendulum）。
- **🟡 PARTIAL**：数学核可验证，但论文的核心说服力依赖不可验证件
  （如 Diffusion Policy：动作头数学 ✅，真机成功率 ❌）——**这是具身论文最常见的档**。
- **❌ NOT-REPRODUCIBLE-HERE**：无数学件（Q1 否）或数学件全依赖不可得资源。
  产出 WHY-NOT 报告；明确声明"这不是方法有错，是本环境不验证这类"。

判定必须给三行理由：可验证件清单 / 不可验证件清单 / 缺什么。

## 5. 具身论文的典型"必须诚实"清单（默认进 GAP_LIST）

- 真机成功率与任务完成表（对所有 sim/real benchmark 数字）；
- sim2real gap 与域随机化效果；
- 视觉编码器/策略网络的训练动态与消融；
- 与 baseline 的对比实验（除非 baseline 本身可数学验证）。

## 6. 已核实的事实记录（避免引用错误，逐条标注来源与核实日期）

- Diffusion Policy（arXiv:2303.04137）**不含**指数加权 temporal ensembling——
  它是 receding-horizon 承诺执行 + 可选 warm-start；推理用 iDDPM（仿真，平方余弦
  调度）或 DDIM（真机，100 训练步/10 推理步）；典型 T_p=16、T_a=8。
  （ar5iv 原文核实于 2026-09-26）
- 指数加权 temporal ensembling 属于 ACT（arXiv:2304.13705 §IV-A）：
  `w_i = exp(−m·i)`、`a_t = Σ_i w_i A_t[i] / Σ_i w_i`，chunk size k=100。
  （ar5iv 原文核实于 2026-09-26）

**教训**：这两条极易混用（社区文章常张冠李戴）。所有"论文 X 用了 Y"的陈述，
S1 阶段必须对着原文核实——本项目自己的第一个具身预检就纠正了一处记忆错位。
